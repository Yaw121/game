# Number Hunt Online v2

Two-player real-time number hunt for phones and browsers.

## New in v2
- 20-second live round timer
- Speed-based scoring (+100 base plus speed bonus)
- Wrong tap penalty (-5)
- Timeout penalty (-10)
- Average find time and miss tracking
- Easy (1-50), Normal (1-100), Hard (1-150)
- Phone vibration + simple sound feedback
- Share/copy room code
- Rematch button
- Mobile-first board layout

## Deploy on Render
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Root directory: leave blank

Upload/replace the six files at the repository root, then deploy latest commit.
